# Roadmap

Roadmap items are directional plans, not commitments or guarantees.

## Near term

- Improve Xcode target, scheme, archive-configuration, and bundle-membership resolution.
- Expand built-product inspection without changing signing or developer data.
- Add more StoreKit 2 transaction, restore, refund, and subscription-state fixtures.
- Add focused fixtures for UIKit, React Native, Flutter, Capacitor, and Expo native builds.
- Improve App Store Connect evidence import while keeping live records explicitly unverified.
- Expand false-positive regression coverage for comments, generated code, shared frameworks, and multi-app repositories.

## Later

- Optional structured schema for device, Sandbox, and reviewer-route evidence.
- Safer automated source-registry drift detection for living Apple pages.
- More localization and String Catalog checks.
- Additional built privacy-manifest and third-party SDK inventory checks.
- Machine-readable output schema documentation and compatibility tests.

## Out of scope

- Guaranteeing App Store approval.
- Automatically submitting, signing, notarizing, or uploading apps.
- Inventing legal, privacy-policy, consent, or App Store metadata text.
- Replacing device testing, StoreKit Sandbox, App Store Connect, or qualified legal review.
